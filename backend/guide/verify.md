# Check a printed copy

**Where:** `/verify`, or by scanning the QR code on a printed page (`/verify/<code>`). **Who:** everyone; no account needed.

<a id="verify-form"></a>
## Enter the code

Type the code printed under the QR code, for example `UG-7K3P-92QD` for a timetable or `LOG-7K3P-92QD` for an activity report, and click **Check**. Spaces and capital letters don't matter.

## What the result means

### Timetables

| Result | Meaning |
|---|---|
| **Genuine and current** | This is the current FINAL timetable. The page shows the programme, timetable, session, semester and when it was marked FINAL. |
| **Genuine, but may be out of date** | It was FINAL, but has since been reopened for changes. The printed copy may no longer match; download the latest version. |
| **Out of date** | A newer FINAL version has been issued. Use the newer one. |
| **Not recognised** | No timetable or report has this code. Check it was typed exactly as printed; if it was, the copy may not be genuine. |

### Activity log reports

**Genuine activity log report** confirms UniSchedule generated it. The page shows the reference, programme, period covered, number of matching events, format and when it was generated. Compare them with your copy. It never shows whose activity the report covers.
